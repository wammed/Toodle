本書は、**Toodle** クロックウィジェットおよび設定アプリ（`toodle-settings`）の全操作体系、マウス・キーボード操作、ポップアップサーフェスの操作方法、および `Edit Layout` モードの使い方を網羅したリファレンスガイドです。

---

## 🧭 主な操作クイックリファレンス

| 操作対象 | アクション / 入力 | 実行される動作 |
| :--- | :--- | :--- |
| **ウィジェット本体** | **右クリック** (時計・天気の領域内) | **コンテキストメニュー** を表示 (`Calendar`, `Weekly Forecast`, `Edit Layout`, `Settings`, `Quit`) |
| **ウィジェット本体** | **左クリック** (時計・天気の領域外) | **背後のデスクトップへクリック透過** (Input Region 最小化設計) |
| **ポップアップ群** | **外側をクリック** または **`Esc` キー** | 表示中のポップアップ（メニュー、カレンダー、天気予報）を閉じる |
| **カレンダー** | **「<」「>」ボタンをクリック** | 前月 / 翌月へスムーズに切り替え |
| **カレンダー** | **「今日」ボタンをクリック** | 現在の当月・当日表示へ即時ジャンプ |
| **Edit Layout Panel** | **9ゾーンボタン** (TopLeft 〜 BottomRight) | ウィジェットの配置位置をデスクトップ上で瞬時に移動 |
| **Edit Layout Panel** | **1〜10 サイズスライダ / ボタン** | ウィジェットの表示寸法をインプレースでリアルタイム変形 |
| **Edit Layout Panel** | **Save ボタン** | 変更した位置・サイズを `~/.config/toodle/config.toml` に保存して終了 |
| **Edit Layout Panel** | **Cancel ボタン** | 変更前の位置・サイズに巻き戻して編集モードを終了 |
| **設定アプリ** | **設定項目の変更** | 変更と同時に `config.toml` へ自動保存され、ウィジェットへ即時反映 |

## 1. ウィジェット本体のマウス操作

Toodle のウィジェット本体は、デスクトップ壁紙の直上層である `Layer::Bottom` に常駐します。

- **Input Region（入力領域）の局所化**:
  - ウィジェットは画面全体を覆う透明な領域を持たず、時計と天気情報が表示されている最小矩形（`content_bounds`）のみを入力受付領域として Wayland コンポジタに宣言します。
  - そのため、ウィジェットの周囲の何もないデスクトップ領域をクリックしても、Toodle に遮られることなく壁紙のコンテキストメニューやデスクトップアイコンが正常に反応します。
- **右クリック**:
  - ウィジェットの表示領域内で右クリックすると、`Layer::Top` に独立したコンテキストメニュー（340×380 ピクセル）が表示されます。

---

## 2. ポップアップサーフェス群 (`Layer::Top`)

コンテキストメニューから以下の各種ポップアップを開くことができます。これらはデスクトップ壁紙に左右されない**ソリッドダーク背景**を採用しており、どのような壁紙でも抜群の視認性を誇ります。

### ① 月間カレンダー (Calendar)
- **寸法**: 680 × 720 ピクセル
- **操作**:
  - 上部の「`<`」「`>`」ナビゲーションボタンで前後の月へ移動できます。
  - 「今日」ボタンを押すことで、何ヶ月離れていても即座に本日の月に戻り、本日の日付セルが明瞭にハイライトされます。
  - ポップアップ外をクリックするか、右クリックで閉じることができます。

### ② 7日間週間天気予報 (Weekly Forecast)
- **寸法**: 680 × 720 ピクセル
- **表示内容**:
  - 今後 7 日間の日付・曜日
  - Bas Milius Meteocons による鮮やかなカラーベクター天気アイコン
  - 各日の最高気温 / 最低気温バー
  - 降水確率（%）の明瞭な表示
- **操作**:
  - 閲覧専用ポップアップです。ポップアップ外をクリックして閉じます。

## 3. Edit Layout モード (直感的レイアウト変更)

コンテキストメニューから **`Edit Layout`** を選択すると、Toodle 独自の **2サーフェス編集モード** に移行します。

```text
┌────────────────────────────────────────────────────────┐
│  Desktop (Wayland)                                     │
│                                                        │
│  ┌───────────────────────┐                             │
│  │   Edit Layout Panel   │ (Layer::Top 独立操作盤)      │
│  │   [ 3x3 Grid Buttons] │                             │
│  │   [ 1-10 Size Slider] │                             │
│  │   [ Save ] [ Cancel ] │                             │
│  └───────────┬───────────┘                             │
│              │ In-place Layer Commands (リアルタイム)   │
│              ▼                                         │
│  ┌───────────────────────┐                             │
│  │  Toodle Widget (Live) │ (Layer::Bottom ウィジェット) │
│  └───────────────────────┘                             │
└────────────────────────────────────────────────────────┘
```

1. **ゼロフリッカーのインプレース変形**:
   - 画面上部に操作用の `Edit Layout Panel` が表示されます。
   - 位置ボタン（TopLeft, TopCenter, TopRight, MiddleLeft, Center, MiddleRight, BottomLeft, BottomCenter, BottomRight）をクリックすると、ウィジェットがその位置へ瞬時に移動します。
   - サイズ段階（Stage 1: 280px 〜 Stage 10: 2060px）を変更すると、フォントやアイコンの拡大率がリアルタイムに連動して伸縮します。
   - サーフェスの破棄・再生成を行わないため、画面のチラつき（Flicker）は一切発生しません。
2. **確定とキャンセル**:
   - **Save**: 現在のプレビュー状態を設定ファイルにアトミック保存し、編集モードを終了します。
   - **Cancel**: 編集開始前のレイアウトに復元して編集モードを終了します。

## 4. 独立設定アプリ (`toodle-settings`)

`toodle-settings` は、詳細なデザインや天気地点をじっくり設定するための XDG Toplevel ウィンドウ（720 × 780）です。

- **Appearance（外観）タブ**:
  - 10 種類のテーマプリセット（Modern, Classic, Digital Mono, Cyberpunk, Nord, Warm Sunset, Forest, Slate, Rose Gold, Minimal）の選択。
  - 16 色のカラーパレットからの色指定、テキストシャドウの ON/OFF 切り替え。
- **Layout（配置・寸法）タブ**:
  - 9 分割ゾーンの選択、および 10 段階のサイズスライダ。
- **Weather（天気）タブ**:
  - 主要都市のクイック選択ドロップダウン（東京, ニューヨーク, ロンドン, パリ, シドニー 等）。
  - 緯度（Latitude）・経度（Longitude）の手動直接入力。
  - 温度単位の切り替え（Celsius ℃ / Fahrenheit ℉）。
- **Display（画面出力）タブ**:
  - マルチモニター環境における対象ディスプレイ（例: `"DP-1"`, `"HDMI-A-1"`）の割り当て。

> 💡 **ホットリロード連携**:
> 設定アプリで値を変更した瞬間に、inotify 監視を通じて常駐ウィジェットに約 25〜50ms で自動反映されます。保存ボタンを押す手間すら不要です。
