# Toodle 機能仕様書 (Feature Specification)

本ドキュメントは、COSMIC Desktop Environment 向けデジタルクロックウィジェット **Toodle** の各機能および仕様について詳細に解説します。

---

## 1. デジタル時計 & 日付表示

- **高精度デジタル時計**:
  - `HH:MM:SS`（時:分:秒）形式の24時間表示。
  - サブセカンド同期ストリームにより、CPUリソースを浪費することなく物理時計の1秒境界に正確に合致して更新。
- **フル日付表示**:
  - 曜日、月名、日、年を表示（例: `Monday, September 20, 2026`）。
- **ダイナミックフォントスケーリング**:
  - 30%（`0.3x`）から 1000%（`10.0x`）まで自由に拡縮可能。文字潰れやクリッピングを防止。
- **テキストドロップシャドウ**:
  - 柔らかいアンビエントシャドウ（`Color::from_rgba(0, 0, 0, 0.65)`, オフセット: `(1.0, 2.0)`, ぼかし: `6.0px`）の ON/OFF が可能。明るい壁紙上でも優れた可読性を維持。

---

## 2. 天気情報 & 週間予報サブシステム

- **現在天気表示**:
  - 天候テキスト（例: `Clear sky`, `Partly cloudy`, `Rain`）および現在気温を表示。
  - 気温単位は摂氏（`°C`）と華氏（`°F`）を即座に切り替え可能。
- **7日間週間予報ポップアップ (`680 x 720`)**:
  - 右クリックメニューからワンクリックで展開。
  - 向こう7日間の日別カード表示（例: `Mon, Sep 21`）。
  - 当日には `(Today)` バッジを明示。
  - 最低気温、最高気温、天候状況、および高コントラストな見やすいデザイン。
- **2段階永続キャッシュ & 座標検証**:
  - 現在天気は30分間ローカルキャッシュ。
  - 週間予報は3時間ローカルキャッシュ。
  - 座標バリデーション（`is_location_match`）により、設定で都市を変更した瞬間に古いキャッシュをバイパスして最新データを取得。
  - オフライン時自動フォールバック：ネットワーク障害時は前回の有効キャッシュを安全に継続表示。

## 3. ポップアップサーフェス (`Layer::Top`)

### 3.1 コンテキストメニュー (`340 x 380`)
- ウィジェット上での右クリックでデスクトップ最前面に展開。
- 不透明ダークソリッド背景（`Color::from_rgb(0.13, 0.14, 0.18)`）、上品なボーダー、ドロップシャドウ。
- 18pxフォント、中央揃えのわかりやすいボタン構成：
  - `Calendar`: 月間カレンダーを展開。
  - `Weekly Forecast`: 7日間週間予報を展開。
  - `Edit Layout`: デスクトップ上でのレイアウト編集モードを開始。
  - `Settings`: 設定アプリ（`toodle-settings`）を起動。
  - `Quit`: ウィジェットデーモンを安全に終了。

### 3.2 月間カレンダーポップアップ (`680 x 720`)
- 年・月および整然とした7列のカレンダーグリッドを表示。
- 曜日ヘッダー: `Mon`, `Tue`, `Wed`, `Thu`, `Fri`, `Sat`, `Sun`。
- インタラクティブな月送り操作：
  - `<` (前月へ移動)
  - `Today` (現在の月・日へ即座に戻る)
  - `>` (翌月へ移動)
- 本日の日付はハイライトカラー（suggestedスタイル）で際立たせて表示。

## 4. デスクトップレイアウト編集モード (Edit Layout Mode)

- デスクトップ上でウィジェットの配置・寸法を直接視覚的に調整できる機能。
- 特徴：
  - 青色の境界枠でウィジェットのサーフェス領域を可視化。
  - `Save` ボタン：調整結果を `config.toml` に保存し、通常モードへ復帰。
  - `Cancel` ボタン：編集途中の変更を破棄し、以前の設定へ復帰。
  - モードの開始・終了時にも画面のチラつき（フリッカー）はゼロ。

---

## 5. 独立設定アプリケーション (`toodle-settings`)

XDG Toplevel ウィンドウ（720 x 780）として動作する設定アプリ。4つのタブで構成：

### 5.1 Appearance (外観) タブ
- **テーマプリセット一覧**:
  - フォント名バッジ付きの10プリセット：`Modern`, `Classic`, `Digital Mono`, `Minimal`, `Cyberpunk`, `Nord`, `Warm Sunset`, `Forest`, `Slate`, `Rose Gold`。
  - プリセットをクリックするとフォントとカラーがウィジェットへ即座にリアルタイム反映。
- **16色固定カラーパレット**:
  - チェックマーク（`✓`）と高コントラスト枠付きのカラースウォッチ。
  - 純白、シルバー、スレート、スカイブルー、COSMICブルー、インディゴ、パープル、ローズピンク、クリムゾン、コーラルレッド、オレンジ、アンバーゴールド、サンイエロー、ライム、エメラルドグリーン、ティールシアン。
- **フォントスケールスライダー**: `30%` 〜 `1000%`（5%刻み）。
- **テキストシャドウトグル**: 文字のドロップシャドウを即座にON/OFF。

### 5.2 Layout (配置) タブ
- **デスクトップアンカー**: `TopLeft`, `TopRight`, `BottomLeft`, `BottomRight` の4点から選択。
- **マージン X / Y スライダー**:
  - 範囲：`0..=2560 px` (X), `0..=1440 px` (Y)（2px単位）。
  - 負の値を排除し、画面外への誤飛び出しを防止。
- **幅 / 高さ スライダー**:
  - 幅: `150..=1200 px`（5px単位）。
  - 高さ: `60..=800 px`（5px単位）。
- **リアルタイム反映**: スライダーを動かした瞬間からウィジェットがデスクトップ上で滑らかに追従。

### 5.3 Weather (天気) タブ
- **ロケーション入力**: `Location Name`、`Latitude`（緯度）、`Longitude`（経度）。
- **クイック都市プリセット**:
  - ワンクリックボタン：`Tokyo`, `Gifu`, `London`, `New York`, `Paris`。
  - 現在選択中の都市にはチェックマーク（`✓`）を表示。
  - クリック時に即座に保存・キャッシュバイパス・天気更新を実行。
- **Apply Location & Refresh Weather ボタン**: 手動入力した座標を即座に適用。
- **気温単位切り替え**: `Celsius (°C)` と `Fahrenheit (°F)`。

### 5.4 Display (ディスプレイ) タブ
- 出力先 Wayland モニター名（例: `DP-1`, `HDMI-A-1`）を指定可能。空文字でプライマリ/アクティブモニターへ自動配置。

## 6. バイナリ組み込みフォント (設計第10項準拠)

以下の4フォントファミリ（計8ファイル）をバイナリへ組み込み済み：
1. **Roboto Sans** (Regular / Bold) — Modern, Forest テーマ用。
2. **JetBrains Mono** (Regular / Bold) — Digital Mono, Cyberpunk, Slate テーマ用。
3. **DejaVu Serif** (Regular / Bold) — Classic, Warm Sunset, Rose Gold テーマ用。
4. **Open Sans** (Regular / Bold) — Minimal, Nord テーマ用。
